# 党史党建复习测试程序

单文件网页版党史 / 党建复习测试程序：打开网页即可做题，无需安装、无需后端。题库已内嵌，离线也能用。

## 🌐 在线使用（推荐）

👉 **直接打开做题**：<https://xiaoxuheibei.github.io/dangshi-review/>

手机、电脑浏览器均可打开，答题进度会保存在本机。

## 📱 Android 版

下载 [review_exam.apk](./review_exam.apk)，传到安卓手机安装即可离线使用（Android 5.0 及以上）。

> 安装时若提示「禁止安装未知来源应用」，按提示给浏览器 / 文件管理器授权即可。

## ✨ 功能

- **📝 模拟测试**：随机组卷，题型分值为 单选 20 分 + 多选 20 分 + 填空 20 分 + 简答 20 分 + 论述 20 分 = 100 分，**合格线 80 分**。客观题自动评分，简答 / 论述作答后自评。
- **📚 练习模式**：按题型逐题练习，可点选项、填答案并即时判对错；单选 / 多选会给出每个选项的错误原因解析（共 542 条）。
- **🔖 错题本**：自动收集模拟测试中的错题，可反复复习、清空。
- **👁 答案提示开关**：练习模式里可随时显示 / 隐藏灰色提示答案（随输入逐字渐隐，不会一敲就全消失）。
- **↑ 一键回顶**、**← 返回**、**✕ 退出** 等辅助操作。

## 📊 题库

共 **236 题**：单选 95、多选 53、填空 60、简答 22、论述 6，并含 542 条选项解析。
